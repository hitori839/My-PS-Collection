# 📚 MY-PS-COLLECTION

이 저장소는 백준(Baekjoon Online Judge)과 프로그래머스(Programmers)에서 해결한 알고리즘 및 코딩 테스트 문제 풀이 코드를 모아둔 공간입니다. Java와 Python을 사용하여 풀이하고 있습니다.

---

## 디렉토리 구조

```text
MY-PS-COLLECTION/
├── BJ_PS_Java/          # 백준 문제 풀이 (Java)
├── BJ_PS_Python/        # 백준 문제 풀이 (Python)
└── Programmer_test/     # 프로그래머스 문제 풀이
    ├── PT_Java/         # 프로그래머스 (Java)
    └── PT_Python/       # 프로그래머스 (Python)
```

## 기술 스택 (Tech Stack)

```text
- Languages: Java, Python
- Platforms: Baekjoon Online Judge, Programmers
```
